Kom igång

Skicka nyckeln i Authorization-headern. Bas-URL: https://budradar.vercel.app/v1

curl -H "Authorization: Bearer br_live_XXXX" https://budradar.vercel.app/v1/flags?since=2026-11-01

Kvot per dygn (UTC). Svaren har X-RateLimit-Limit och X-RateLimit-Remaining. Fel: 401 saknad/ogiltig nyckel, 403 spärrad, 429 kvot slut.

Endpoints

GET/v1/flags

Bidco-flaggor i realtid, nyast först. Parametrar: since (ISO-datum), limit (max 500), outcome (pending|hit|miss|expired), historical=1 för att ta med verifierade historiska bud.

{
  "count": 1,
  "data": [{
    "id": 30, "name": "AB AOEG HoldCo", "org_nr": "5595961631",
    "reason": "bolagsverket_bulk_registrering+bidco_namnmonster", "score": 50,
    "address": "…", "advisor": null, "registered_at": "2026-08-03",
    "flagged_at": "2026-08-10T06:10:51.582Z", "outcome": "pending",
    "proof": { "row_hash": "…", "prev_hash": "…", "github_commit_sha": null }
  }]
}
GET/v1/flags/{id}

En enskild flagga med fullständigt hashbevis.

GET/v1/watchlist

Nyregistrerade lagerbolag under 90 dagars bevakning. status: pending (standard), flagged, expired.

GET/v1/bids

Budregistret: budgivare, premier, bidco-kedja, tidslinje och utfall. Filter: from, to, bidderType, hasBidco=1.

GET/v1/candidates

Hela uppköpslistan med poäng, motivering och backtest.

GET/v1/verify

Verifierar hela hashkedjan i realtid.

GET/v1/me

Din plan, kvot och förbrukning idag.
